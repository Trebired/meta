Publishing a site is not the same as being findable. Once the initial release is out, every page states what it is in a form a search engine can read: a title and description written for a reader rather than a crawler, canonical addresses, a sitemap, and structured data that matches what the page actually says.

None of it buys attention. The organization does not pay for placement, and it does not write pages for ranking that a person would not want to read. The work is making what is already true about a page legible to the machines that index it.
